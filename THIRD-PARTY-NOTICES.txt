Third-Party Notices
===================

FanControl.LianLi is licensed under the MIT License (see LICENSE).

The plugin ships as a single DLL and contains no third-party components. It
reaches the controllers through Windows' own hid.dll, winusb.dll, cfgmgr32.dll
and kernel32.dll, and it compiles against FanControl.Plugins.dll, the host's
plugin contract, which every FanControl install provides and this plugin does
not redistribute.

The tools used to build and test the plugin (the .NET SDK, xUnit and coverlet)
are not part of what it ships.
